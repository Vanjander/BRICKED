

# AGENTS.md – BRICKED

## Projekt
BRICKED er et begyndervenligt website om LEGO som kreativ hobby for voksne.

                                                                    Websitet er et skoleprojekt med fire sider:
- index.html
- kom-i-gang.html
- foerste-projekt.html
- inspiration.html

## Teknologi
- HTML5
- CSS3
- Vanilla JavaScript, kun hvis nødvendigt
- Ingen frameworks, biblioteker, CDN eller build tools
- Ingen backend, database eller login
- Websitet skal kunne åbnes direkte i en browser

## Projektstruktur
- HTML-filer ligger i projektets rod
- CSS ligger i assets/css/style.css
- JavaScript ligger i assets/js/
- Billeder ligger i assets/images/
- Alle sider skal bruge den samme CSS-fil

## Design
Følg det godkendte Figma-design for både desktop og mobil.

Farver:
- Baggrund: #F2EADE
- Tekst: #593D35
- Sekundær: #A8B59A
- Highlights: #D9B86C
- Knapper: #3F5546

Typografi:
- Overskrifter: DM Serif Display
- Brødtekst, navigation og knapper: Inter

Desktop-designet er lavet i 1440 px.
Mobil-designet er lavet i 390 px.

Desktop bruger blandt andet 20 px stor brødtekst.
Mobil har bevidst mindre tekststørrelser.

## Typografi
- BRICKED-logo: Do Hyeon (bruges udelukkende til logoet)
- Overskrifter: DM Serif Display
- Brødtekst, navigation og knapper: Inter
- Bevar skrifttyper, størrelser og vægtninger fra Figma.
- Do Hyeon må kun bruges til BRICKED-logoet.

## Kodestandard
- Brug semantisk HTML5
- Brug CSS Grid og Flexbox, hvor det passer til designet
- Skriv overskuelig og vedligeholdelsesvenlig kode
- Brug beskrivende klassenavne
- Sørg for responsivt layout
- Brug relative filstier
- Tilføj alt-tekster til indholdsbilleder
- Sørg for fungerende navigation på alle fire sider

## Arbejdsregler
1. Læs AGENTS.md og relevante projektfiler før ændringer.
2. Følg Figma-designet. Opfind ikke nye sektioner eller funktioner.
3. Brug billeder fra assets/images/.
4. Gæt ikke på billedfilnavne eller manglende indhold.
5. Ændr ikke projektstrukturen uden tilladelse.
6. Bevar eksisterende kode og design, medmindre en ændring er nødvendig.
7. Arbejd kun med den opgave, der konkret bliver bedt om.
8. Spørg, hvis en vigtig oplysning mangler.
9. Kommunikér på dansk.
10. Afslut med en kort oversigt over ændrede filer og eventuelle problemer.
